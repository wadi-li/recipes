# Рецепты

Единый кулинарный каталог: супы-пюре, су-вид и туристическое питание.

Сайт: https://wadi-li.github.io/recipes/

## Разделы
- [Супы-пюре](https://wadi-li.github.io/recipes/soups/)
- [Су-вид](https://wadi-li.github.io/recipes/sous-vide/)
- [Туристическое питание](https://wadi-li.github.io/recipes/tourism/)

Главная страница содержит поиск по продукту и фильтры по типу питания, калорийности и приёму пищи. Показатели пищевой ценности предварительные.
