## О проекте

**«Рецепты»** — открытая кулинарная веб-библиотека с поиском блюд, справочными сведениями о приготовлении, подбором по принципам питания и мастером недельного меню. Сайт работает как статический веб-проект на GitHub Pages: для просмотра рецептов не требуется регистрация.

Каталог объединяет **75 карточек рецептов**. Для **69 рецептов** создана структурированная база ингредиентов (справочник из **73 продуктов**) с расчётными показателями пищевой ценности; **6 справочных карточек** (3 су-вид и 3 походных блюда) пока не имеют полной структурированной рецептуры и не показывают выдуманные значения КБЖУ. Дополнительно раздел «Су-вид» содержит **34 блюда** с температурными режимами, а раздел «Туризм» — отдельный планировщик походного рациона.

Каждая карточка блюда сопровождается **собственной иллюстрацией, точно соответствующей названию и составу блюда** — см. раздел [«Иллюстрации блюд»](#иллюстрации-блюд).

### Карточка блюда

Карточки во всех разделах построены по единому шаблону:

- иллюстрация блюда;
- метки категорий: калорийность, приём пищи, тип питания, категория горячего блюда и диетические принципы;
- краткая формула рецепта и КБЖУ на порцию;
- кнопки **«Открыть рецепт»** и **«Печать / PDF»** (ссылка `recipe/?id=N&print=1` сразу открывает диалог печати).

Переключатель **«Отобразить / скрыть категории»** сохраняет выбор в браузере и действует на всех страницах.

## Поиск и классификация

На главной странице доступны фильтры по **названию и ингредиентам**, **разделу**, **приёму пищи**, **калорийности** и **принципам питания**.

В каталоге представлены категории: веганское, вегетарианское, мясное и рыбное питание; диетическое, диабетическое, безглютеновое, бессолевое, низкоуглеводное и «источник клетчатки». Для принципов питания предусмотрены пояснения при наведении курсора или выборе категории.

**Калорийность на 100 г:** низкая — менее 100 ккал, средняя — 100–200 ккал, высокая — более 200 ккал. Классификация ориентировочная.

> Диетические метки — кулинарная классификация, а не подтверждение медицинской пригодности блюда. При диабете важно учитывать углеводы и назначенную терапию; при целиакии — состав и риск перекрёстного загрязнения; при ограничении натрия — содержание соли в исходных продуктах.

## Мастер «Меню на неделю»

[**Открыть мастер недельного меню**](https://wadi-li.github.io/recipes/menu/)

Мастер помогает составить рацион на семь дней из доступных рецептов.

1. **Выберите принципы питания.** Допускается несколько ограничений одновременно. Если для выбранного сочетания не хватает блюд, мастер сообщает об этом вместо подстановки неподходящих рецептов.
2. **Настройте меню:** количество человек (1–20), два или три приёма пищи в день, исключаемые продукты через запятую, дату начала недели.
3. **Создайте меню на семь дней.** В каждом дне можно выбрать другое блюдо из подходящих вариантов и открыть его рецепт.
4. **Получите список покупок.** Одинаковые ингредиенты суммируются по всем выбранным блюдам с учётом числа человек.
5. **Сохраните или экспортируйте результат.** Доступны сохранение меню в браузере, копирование, печать/PDF и скачивание списка покупок в CSV.

Поля настроек имеют адаптивную ширину: на широком экране размещаются в одной строке, на небольших экранах перестраиваются в две или одну колонку.

### Как рассчитываются покупки

Для каждого рецепта используются **структурированные ингредиенты**: идентификатор продукта, количество и единица измерения. Мастер суммирует количества одинаковых продуктов, а не пытается извлечь их из произвольного текста рецепта. Вода не включается в закупочный список.

Исходная порционность в текущей базе: **4 порции для супов**, **2 порции для горячих блюд, салатов и диетических блюд**. Количества пропорционально пересчитываются на число человек. Для блюд без полной рецептуры точный список покупок не формируется.

## КБЖУ и клетчатка

Для структурированных рецептов выводятся:

- **К** — калорийность, ккал;
- **Б** — белки, г;
- **Ж** — жиры, г;
- **У** — углеводы, г;
- **Клетчатка**, г.

Значения рассчитываются **на порцию и на 100 г** по одной базе продуктов. В ней предусмотрены усреднённые показатели на 100 г ингредиента и количество каждого ингредиента в рецепте. Это позволяет использовать общие исходные данные для карточек рецептов и недельного планировщика.

Для горячих блюд КБЖУ на порцию — сумма по граммовке всех ингредиентов, включая масло и соус, делённая на 2. Крупы указаны в сухом виде, нут и фасоль — уже отваренными без жидкости, мясо и рыба — в сыром виде, креветки — варёными. Оценочный выход готового блюда хранится в поле `estimatedCookedWeightG`.

**Важно:** значения приблизительные. Текущий расчёт не моделирует изменение массы при приготовлении, испарение воды, технологические потери, конкретные торговые марки и необязательные добавки. Указанная масса порции — расчётная, а не измеренная масса готового блюда. Для медицинских диет необходимо отдельно учитывать индивидуальные требования.

## Иллюстрации блюд

**Фотографии в карточках теперь в точности соответствуют блюдам.** Ранее карточки использовали случайные фотографии с Unsplash, не отражавшие содержание: одна и та же картинка повторялась у 30 рецептов, а все 25 горячих блюд показывали одно изображение. Теперь у каждого блюда — своя иллюстрация, созданная по его названию и составу: супы-пюре показаны в виде крем-супов нужного цвета с характерными ингредиентами, походные блюда — в туристической посуде, блюда для офиса — в ланч-боксе, пайки су-вид — с вакуумной упаковкой.

| Набор | Количество | Каталог | Где используется |
|---|---:|---|---|
| Карточки рецептов | 75 | `assets/img/dishes/r{id}.webp` | главная, горячие блюда, супы, салаты, диеты, контейнер в офис, страница рецепта |
| Блюда су-вид | 34 | `assets/img/sous-vide/sv{N}.webp` | раздел «Су-вид» и карточка блюда су-вид |

Характеристики изображений:

- единый стиль: реалистичная подача блюда при дневном свете на светлой посуде и нейтральном фоне, без текста и логотипов;
- формат **WebP**, ширина 800 px, соотношение сторон около 4:3; общий объём ≈ 6 МБ;
- все файлы хранятся **в репозитории** — сайт не зависит от внешних фотохостингов и работает при локальном открытии без интернета;
- в разделе «Горячие блюда» иллюстрации добавлены в карточки (ранее карточки были без изображений).

Иллюстрации сгенерированы специально для этого проекта и показывают типичную подачу блюда; реальный результат приготовления может отличаться посудой, сервировкой и оттенком. Авторство и условия использования — в разделе [«Лицензия и авторство иллюстраций»](#лицензия-и-авторство-иллюстраций).

### Как устроены пути к изображениям

- В `assets/recipes-data.js` поле `image` хранит путь относительно папки `assets/`, например `img/dishes/r58.webp`. В конце файла путь автоматически преобразуется в полный адрес относительно расположения скрипта, поэтому одно значение работает и на главной странице, и во вложенных разделах.
- В `sous-vide/index.html` изображение выбирается функцией `svImg(i)` по индексу блюда в массиве `items`: `assets/img/sous-vide/sv{i}.webp`.

### Как добавить новое блюдо с иллюстрацией

1. Добавьте рецепт в `window.RECIPES_DATA` с новым `id`.
2. Положите иллюстрацию в `assets/img/dishes/r{id}.webp` (WebP, 800 px по ширине, 4:3).
3. Укажите `"image":"img/dishes/r{id}.webp"`.
4. Для су-вид: блюдо добавляется в конец массива `items` (или через `items.push`), файл называется `sv{индекс}.webp`. **При изменении порядка блюд су-вид файлы нужно переименовать соответственно.**

### Единая модель данных

Файл `assets/recipes-data.js` содержит:

- `window.RECIPES_INGREDIENTS` — справочник продуктов с названиями, единицами и нутриентами;
- `window.RECIPES_DATA` — карточки рецептов, состав, инструкции, категории и исходную порционность;
- `ingredientsStructured` — массив ингредиентов рецепта с `ingredientId`, `amount` и `unit`;
- `yieldServings` — количество исходных порций;
- `nutrition` — расчётные значения на порцию и 100 г;
- `image` — путь к иллюстрации блюда относительно `assets/`;
- `hotCategory` — категория горячего блюда (птица, мясо, рыба и морепродукты, бобовые, овощи и яйца);
- `office`, `officeNote` — пригодность для ланч-бокса и примечание по перевозке;
- `estimatedCookedWeightG` — оценочный выход готового блюда, г.

Файл `assets/recipe-ui.js` (`window.RECIPES_UI`) формирует общие элементы карточек: метки категорий, кнопки «Открыть рецепт» и «Печать / PDF», переключатель видимости категорий.

При изменении состава или количества ингредиентов **показатели КБЖУ пересчитываются из общей модели**. Список покупок использует те же `ingredientsStructured` и `yieldServings`. Для шести неполных карточек `ingredientsStructured = null` и `nutrition = null`.

## Как запустить локально

Проект не требует сборщика, сервера приложений или установки пакетов.

1. Скачайте репозиторий через **Code → Download ZIP** либо выполните:
   ```bash
   git clone https://github.com/wadi-li/recipes.git
   ```
2. Откройте `index.html` в браузере.
3. Для проверки поведения как на GitHub Pages можно запустить простой локальный HTTP-сервер из каталога проекта:
   ```bash
   python -m http.server 8000
   ```
   Затем откройте `http://localhost:8000/`.

Сохранение меню использует локальное хранилище браузера (**localStorage**): данные остаются на конкретном устройстве и не синхронизируются между браузерами.
