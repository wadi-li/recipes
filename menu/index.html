Мастер «Меню на неделю»

Подбор семи дней по принципам питания с возможностью замены блюд, печати и сохранения.

1. Выберите принципы питания

Можно сочетать ограничения. Веганское питание автоматически исключает продукты животного происхождения. При нескольких строгих ограничениях выбор блюд может оказаться небольшим.

2. Настройки меню

Указанные в рецептах ингредиенты рассчитаны на исходное количество порций; мастер не пересчитывает автоматически граммовки. Проверяйте количество продуктов перед закупкой.

Одинаковые ингредиенты суммируются. Укажите число порций, которое даёт один рецепт: для супов исходно 4, для остальных карточек число порций уточните по рецепту. Неуказанные количества выделяются отдельно.

Это кулинарный планировщик, а не медицинское назначение. Не рассчитывает индивидуальные углеводы, ХЕ, калий, фосфор, натрий, белок или энергетическую потребность. Для диабета важны углеводы и терапия; для болезней почек ограничения определяются врачом. «Без добавленной соли» не означает отсутствие натрия.
